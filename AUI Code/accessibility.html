Accessibility

AUI aims to meet WCAG 2.2 level AA. Each release is scanned with axe-core with no violations found; we have not yet tested it by hand with every screen reader.

What works today

  • Keyboard: every control can be reached with Tab. Skip links jump to the message box, the conversation and the chat list. Ctrl/⌘ + K, / and , open a new chat, search and settings, and you can change those letters in Settings, Accessibility.
  • Screen readers: new replies are announced when they finish, unread chats say so, code blocks and charts have labels, and charts include a hidden data table.
  • Seeing the screen: high-contrast and OLED themes, text size up to 150%, the Atkinson Hyperlegible and Lexend fonts, a reading ruler, one-paragraph focus, and a Pause button that freezes the text while AUI keeps writing.
  • Motion: AUI follows your system's reduced-motion setting, and effects can be turned off in Settings, Appearance.
  • Language: a "simple language" switch asks AUI for plain words and short sentences. Right-to-left messages (Hebrew, Arabic) are laid out right to left.
  • Listening: any reply, or any text you select, can be read aloud in the voice you choose.

Known gaps

  • Diagrams drawn from Mermaid code have no text description beyond their source code.
  • AUI cannot describe pictures yet, because the in-browser models don't see images.
  • Manual testing with NVDA, JAWS, VoiceOver and TalkBack is still to do.

Report a problem

If something gets in your way, open an issue at github.com/usernam69/AUI/issues and say which browser and assistive technology you use.
